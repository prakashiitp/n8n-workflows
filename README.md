# n8n Workflows

A collection of practical AI-powered and automation workflows built with **n8n**, covering AI Agents, LLM applications, RAG, MCP, APIs, databases, and real-world automation use cases.

## Workflows

| Workflow | Description | Status |
|----------|-------------|--------|
| **AI Chat Agent API** | AI-powered conversational agent exposed through an API. | ✅ |
| **AI Email Reply Agent** | AI-powered workflow for generating email replies automatically. | ✅ |
| **Customer Data Filter** | Retrieves customer records, transforms fields, and filters data using conditional logic. | ✅ |
| **Customer Data Processing** | Reads customer data from Google Sheets, transforms required fields, and routes records using an IF node. | ✅ |
| **Customer Feedback AI Agent** | Processes customer feedback using an AI Agent and automates follow-up actions. | ✅ |
| **MCP AI Agent n8n** | AI agent workflow demonstrating MCP integration with n8n. | ✅ |
| **RAG AI Agent n8n** | RAG-based workflow for answering questions using a connected knowledge source. | ✅ |
| **Role-Based AI Content Generator** | Generates personalized AI content based on user roles and input. | ✅ |
| **More workflows coming soon...** | New AI automations, integrations, and practical workflows will be added regularly. | 🚧 |
